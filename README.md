# AREV Fatizal — V2 prête à l'emploi

Site vitrine statique en HTML/CSS/JS, prêt à être déployé sur Vercel, Netlify, GitHub Pages ou un hébergement classique.

## Structure
- `index.html` : accueil
- `services.html` : métiers
- `realisations.html` : galerie
- `a-propos.html` : entreprise
- `mentions-legales.html` : mentions légales
- `style.css` : design
- `script.js` : menu mobile + formulaire
- `assets/` : identité visuelle et médias
- `robots.txt` / `sitemap.xml` : SEO
- `vercel.json` : configuration légère Vercel

## Publication Vercel
1. Importer ce dossier/ZIP dans Vercel.
2. Déployer en Production.
3. Ajouter `arev-fatizal.com` et `www.arev-fatizal.com` dans Domains.
4. Configurer les DNS chez Squarespace selon les valeurs affichées par Vercel.

## Formulaire
Le formulaire prépare un e-mail via `mailto:`. Pour recevoir des formulaires sans ouvrir un logiciel de messagerie, remplacez-le ensuite par Formspree, Resend, un backend ou une API de votre choix.

## Contenu
Les informations d'entreprise présentes dans cette version sont celles utilisées pour la V2. Complétez les mentions légales et les informations réglementaires manquantes avec les données exactes de l'entreprise avant publication définitive.
